<p align="center">
  <strong>Build with your agent. Ship it onchain.</strong><br>
  The release workbench for web projects in the TapeOut ecosystem.
</p>

TapeNow helps creators take a web project they already have and manage its full release lifecycle in one place: import the build, share a private preview, keep every version as a signed archive, publish it onchain, and serve it on a normal HTTPS domain — on **BSC, X Layer and Base**.

With **WebMCP**, your AI agent can inspect projects, prepare releases and run approved operations alongside you inside the workbench; you approve every consequential action.

- Workbench (limited public beta): <https://app.tapenow.dev>
- Homepage: <https://tapenow.dev>
- User manual (English / 中文): <https://app.tapenow.dev/docs/manual/>
